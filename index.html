EDGE FEATURE INSPECTOR

残基ペアの原子間距離と RBF 特徴量

Cα間の距離だけでは残基どうしの向きが分からないため、主鎖4原子（N・Cα・C・O）と仮想原子 Cβ*（N・Cα・C から算出）の計25通りの距離（Å）を使います。セルを選ぶと、その距離に対応する下の RBF 特徴量が切り替わります。

RBF（放射基底関数）特徴量：1つの距離を、中心 2–22 Å（幅 1.25 Å）の16個の応答値へ展開し、ニューラルネットワークが距離の違いを滑らかに識別できるようにします。ここでは数式による計算値を示しており、学習済みモデルの出力ではありません。

02 / CONFORMATIONAL ENSEMBLE & QC

構造ゆらぎの解析と
独立した品質検査

構造生成モデル BioEmu-2 で得た VAMP721–PICALM1a 複合体の8つの構造候補を定量解析しました。モデル標準の品質検査（8/8 合格）を通過した候補に対して独自の重原子衝突検査を実施し、2つの構造で局所的な原子衝突を検出しました。解析処理は型付き Python モジュールにまとめ、CI で自動検証しています。

計算パイプライン

狙った機能を持つタンパク質を設計するため、標的と制約条件の整理、拡散モデルによる構造生成、逆折り畳みによる配列設計、独立モデルを用いた再予測と候補選別までを、一貫した計算パイプラインとして体系化しました。
